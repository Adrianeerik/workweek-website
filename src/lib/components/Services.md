# Services

The "We are Workweek." band: heading, a rule, then three `ServiceCard`s.

## Editing
The `services` array at the top of the file holds each card's `icon`, `title` and `text`.

## Layout
3 columns (32px gap). The gap shrinks to 8px at ≤991px. One column at ≤767px.

## What it replaces
`.section.after-masthead`, `.block-1280`, `.divider`, `.services-grid`.
