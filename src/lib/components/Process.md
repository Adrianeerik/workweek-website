# Process

"Our Process": a heading, four `ProcessStep`s, and a decorative vertical track whose circle sticks at 40% of the viewport height as you scroll.

## Editing
Edit the `steps` array (`image`, `title`, `text`).

## Notes
The track is absolutely positioned against the Section (65% tall, 13% from the bottom, 83px left of centre), the same as the original `.divider-process`. Its circle uses `position: sticky`. Hidden at ≤991px.

## What it replaces
`.section.process`, `.divider-process`, `.slider-circle`.
