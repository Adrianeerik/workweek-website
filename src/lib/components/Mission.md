# Mission

"Our Mission": two stacked images on the left (40%), copy on the right (60%). It's a full-bleed grid using named `grid-template-areas`, so the source order stays copy-first, which is good for screen readers and mobile. The images shrink in at 400ms and 1000ms.

## What it replaces
`.section.mission`, `.mission-grid`, `.container.mission`, `.image.masthead`, `w-node-*` grid areas.
